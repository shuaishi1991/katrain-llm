# KaTrain 大模型解说

本工程基于 [KaTrain](https://github.com/sanderland/katrain) 1.20.0，在原有的围棋对弈和 KataGo 分析上增加了大模型解说。下棋、复盘、AI 对局、引擎设置和快捷键仍按原项目使用，说明见 [KaTrain README](https://github.com/sanderland/katrain/blob/master/README.md)。

## 新增功能

右侧「解说」页用兼容 OpenAI 的对话接口，把 KataGo 的分析讲成可以跟着学的棋理。

* 只有手动点「解说」才会生成。空棋盘的第 0 手点了不会写；先落子，等 KataGo 分析出来再点。
* 每次写两段。第一段讲刚刚这一手的意义、目的和作用。第二段讲 KataGo 推荐的下一手，以及第二、第三选点。两段都会写。
* 标题里带评价，例如「第12手 黑 R14  俗手」。评价按 KataGo 算出的目差确定，模型不能改高或改低：小于 0.5 目、且是最佳选点、次选至少亏 3 目，为妙手；小于 0.5 目为本手；0.5 到 1.5 为缓手；1.5 到 3 为俗手；3 到 6 为恶手；6 到 12 为大恶手；12 目及以上为败着。还没有目差时是未评。亏目为负时按小于 0.5 目计。妙手只给 KataGo 排在第一的那一手。
* 发给模型的资料有棋盘大小、规则名、贴目、从这一路变化的第一手到当前这一手的落子顺序，以及 KataGo 的形势判断和选点。目差、胜率这些数字只给模型判断，解说正文不写出来。
* 解说和追问记在当前这一手上，换一条变化不会串过去。切走再回来，原来的内容还在。再点「解说」只更新解说，已经问过的话留着。「清空」只删这一手。保存棋谱时写在对应的那一手里，下次打开还在。
* 下面的输入框可以追问。追问带上这一手的解说和已经问过的话，以及同一份落子顺序和 KataGo 分析，只回答最新的问题。问「你好」就回问候。
* 解说往外写时可以上下滚动。停在底部附近才会跟着新内容走；往上翻过之后不会被拉回去。
* 解说上面那一块（分析模式下带黄色手数圆点的棋谱树，对局模式下是计时）的下边可以上下拖。往上拖，这一块变矮，下面的解说自动变高；往下拖则相反。松开后会记住。
* 写完的每一段末尾有一个喇叭。点它只朗读这一段，再点一次停止。点另一段会停掉当前这段并改读新的一段。还在往外写的最后一段没有喇叭。正在读的那一段用淡金色标出。切换手数、点「清空」或重新生成解说会停止朗读。
* 朗读使用豆包语音合成 2.0，语速是服务的正常语速。「豆包语音 API Key」和「音色 ID」都填写后才调用该服务。留空，或这一次请求失败，这一段改用系统语音（Windows 用系统语音，Linux 用 espeak 或 speech-dispatcher）。豆包这一段读成功后，不会再叠一层系统语音。

## 安装

需要 Python 3.11、3.12 或 3.13。这个功能只在当前源码里。官方安装包和 `pipx install katrain` 没有它。

在本目录执行：

```bash
pip install .
katrain
```

改过代码后再执行一次 `pip install .`，然后把已经打开的程序完全退出，再重新运行 `katrain`。

Linux 上若启动日志里出现找不到 `xclip` 或 `xsel`，那是剪贴板工具缺失，程序会继续运行。需要复制粘贴棋谱时，安装其中一个即可，例如 `sudo apt install xclip`。

## 配置解说

1. 打开程序，在主菜单点「大模型解说」，或按 F4。
2. 在「API 地址」填写兼容 OpenAI 对话接口的地址。地址由服务商提供，常见结尾是 `/v1` 或 `/api/v3`。例如火山方舟可以填 `https://ark.cn-beijing.volces.com/api/v3`。
3. 在「API Key」填写该服务的密钥。
4. 在「模型名称」填写该服务要求的模型名。上面的火山方舟地址可搭配 `doubao-seed-2-1-lite-260915`。名称要和地址属于同一套接口，不要混用别的产品线里的名字。
5. 勾选「启用解说」。
6. 点「保存」。

然后在右侧打开「解说」页。下完一手并等到 KataGo 分析完成后，点「解说」。生成之后，在底部输入框写问题，点「发送」追问。

## 配置朗读

朗读和上面的对话密钥是分开的，可以不配。不配时，点喇叭会用系统语音。

1. 仍在 F4 的「大模型解说」里。
2. 在「豆包语音 API Key」填写豆包语音的密钥，不是上面的对话密钥。
3. 在「音色 ID」填写音色，例如 `zh_female_vv_uranus_bigtts`。
4. 点「保存」。

两个都填好后，点某一段末尾的喇叭，这一段会用豆包语音读出来。
